# ADR-0008: 低分辨率流体烟雾

- 状态：Accepted
- 日期：2026-10-22
- 背景与问题：V1 需要可被角色搅动、与光照融合的烟雾。OpenGL 4.1（macOS 上限）没有计算着色器，而两个后端必须输出一致。
- 备选方案：CPU 网格求解后上传；GPU 计算着色器；GPU 片元着色器在纹理间来回迭代；粒子模拟烟雾。
- 决策：**GPU 片元着色器实现的 stable fluids**，网格 160×90（每格 2×2 画布像素），全部字段为 RGBA16F：

| 步骤 | Pass | 说明 |
|---|---|---|
| 1 | 速度平流 | 半拉格朗日回溯（线性采样），按“每秒保留比例”衰减；按烟浓度加向上浮力 |
| 2 | 外力 | 最多 8 个高斯喷溅（游戏提供：通风口、角色搅动） |
| 3 | 涡量约束 | 计算旋度，再沿 |旋度| 梯度施力，恢复被粗网格抹平的小涡旋（可关闭） |
| 4 | 散度 | 实心格速度视为 0 |
| 5 | 压力 | Jacobi 迭代（默认 24 次，取偶数），以上一帧压力为初值；实心邻居取中心压力（诺伊曼边界） |
| 6 | 梯度减法 | 得到无散度速度场 |
| 7 | 烟平流 + 烟源 | 两个 pass，结果总是落在同一张纹理中，供合成 pass 固定绑定 |

- 约定：
  - 障碍：游戏把房间实心 Tile 烘焙成 160×90 的掩码（`setFluidObstacles`），房间以外的画布行也视为实心。
  - 时间：游戏把本帧经过的模拟时间交给求解器（`setFluidTimeStep`），每帧最多一步；`--deterministic` 下每帧恰好 1/60 s，保证可复现。
  - 单位：喷溅在世界像素中描述、按“每秒”给出数量，渲染器换算到网格（uv、格 / 秒）并乘以 dt。
  - 合成：烟以 `rgb = 颜色 × 浓度，a = 浓度` 存储；合成时 `mix(场景, 烟颜色 × 光照, 浓度)`，烟被与场景相同的光照（含量化抖动）照亮，暗处的烟不可见；浓度也按光照级数量化。
- 主要理由：片元着色器方案在 OpenGL 4.1 与 Vulkan 上同一条路径，两后端结果一致；低分辨率网格成本低且与像素风相符；烟受光照影响，自然融入场景。
- 代价与风险：每帧约 35 个小 pass（Vulkan 每个 pass 前有布局转换，目前为粗粒度屏障）；没有随房间切换保存烟的状态；一帧最多一步，帧率很低时会显得更“粘”。
- 验证方式：演示房间（通风口 + 角色搅动）运行 300 步后 OpenGL 与 Vulkan 截图逐像素一致（容差 0），Vulkan 验证层（含同步验证）零报错。性能（Apple M2，Release，OpenGL）：完整 V1 场景含烟雾约 2.3 ms / 帧（加入前约 0.9 ms）。
- 重新评估条件：需要更大或多块流体区域、Vulkan 下 pass 数成为瓶颈（可合并 pass 或改用计算着色器路径），或需要液体（水面）而不只是烟。
- 更新（2026-10-23，M3）：GPU 计时（ADR-0016）显示流体是正常场景最大的开销（约 1.3 ms，其中 24 次压力迭代约 0.9 ms，主要是每个小 pass 的固定开销）。两项调整：
  - **休眠**：渲染器记录距上次加入烟的模拟时间；超过“满浓度衰减到 1/512 以下”所需的时间（由 `smokeKeepPerSecond` 算出，0.8 / s 时约 28 s）即停止模拟并不再合成烟，入睡时清空各场；`resetFluid`（换房间）后直接处于休眠，加入烟立即唤醒。没有烟源的房间流体开销约 0.04 ms。`Renderer2D::fluidSleeping()` 供覆盖层显示。
  - **压力迭代 24 → 12**：压力场跨帧保留，每帧从上一帧的解开始迭代；在烟雾深坑对比 24 / 12 / 8 次，烟柱上升、卷曲与贴墙表现无可见退化，取 12。
  - 结果（Vulkan，Release）：有烟房间流体约 0.67 ms，GPU 整帧约 1.75 ms（原约 2.6 ms）。合并喷溅与平流 pass 还能省不到 0.1 ms，暂不做。
