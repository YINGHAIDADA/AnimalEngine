# ADR-0038: 摆动的吊灯、炸药与藤蔓音效

- 状态：Accepted
- 日期：2026-10-24
- 背景与问题：吊灯是静止的道具，碰不到；烟雾流体只是背景效果，没有进入玩法；攀爬和摆荡藤蔓没有声音。
- 决策：
  - **单摆**（`framework/pendulum.h`）：支点、绳长、角度、角速度；重力回复、阻尼、最大摆角。接触时只沿摆动的切向带动重物，带动速率按 `contact / mass` 计算——质量是相对玩家的倍数（默认 4），所以玩家走过只会把吊灯推开一些，然后慢慢摆回；`push` 是瞬时冲量（爆炸），同样除以质量。吊灯（`lantern` 对象）变成单摆：挂链沿绳子逐像素画出（静止时与原来逐像素相同），灯光跟随灯体。参数在参数表中：`lantern.mass`、`lantern.damping`、`lantern.contact`。玩家与爆炸的冲击波作为影响者推动吊灯。
  - **抛射物**（`framework/projectile.h`）：重力下飞行，撞到实心 Tile 时按比例反弹，慢到一定程度就停在地面上，在地面上滑行有摩擦。
  - **炸药**（`game/src/dynamite.cpp`，携带关系在 `framework/loadout.h` 与 `game/src/gear.cpp`）：关卡中的 `dynamite` 对象（底边中点在地面上）碰到即拾取，最多携带 9 个。它是消耗型道具：手持时画在血量下方的框里，图标右下角是数量；可以反复使用的道具只画图标。同一时间只能手持一个道具，**B**（手柄东键）打开缺角边框的菜单：道具是 2×5 的占位格（高亮可移到空位，确认空位无效；消耗品用完后仍在，角上是 0），一条 1px 分界下是 1×5 的能力格（能力同时生效）。重新进入房间时拾取物会再出现，携带数不进存档。手持炸药时，“使用道具”（默认 X / 手柄西键，可改键）把它朝面向的方向抛出（继承一部分玩家速度），引信闪烁越来越快，伴随滴答声，两秒后爆炸：
    - 烟雾流体中一团向上翻滚、向四周推开的烟（`addFluidSplat`，持续 0.5 秒）；
    - 橙色闪光（逐渐减弱的点光源）与爆炸声；
    - 冲击波：半径内的甲虫被炸死（迸出火花），吊灯被推开，玩家被推离（不扣血），草、藤蔓与粒子作为影响者被吹开。
    房间切换时，飞行中的炸药与未散的爆炸留在原房间（清除）。
  - **藤蔓音效**：攀爬时沿藤蔓每移动 7 像素一声沙沙声；在藤蔓上荡起来、速度从低于 70 px/s 越过这一值时一声呼啸（音量随速度，间隔至少 0.45 秒；刚抓住藤蔓的一步不算）。
  - 新增占位音效：投掷、引信、爆炸、拾取、藤蔓攀爬、藤蔓摆荡；新增精灵：炸药（带微弱自发光，暗处与 HUD 上都看得清）。
- 主要理由：单摆与抛射物是独立、可单元测试的小模块；爆炸复用流体、光照、粒子与影响者这些现有系统，没有引入新的渲染路径；质量参数让“不要太轻”变成可调、可测试的量。
- 验证方式：单元测试（单摆静止、被推后摆回并停下、重的比轻的摆幅小得多；抛射物先上升、撞墙与地面反弹、最终静止且不穿墙）；能力测试（拾取炸药、投掷炸死圈里的甲虫且玩家不受伤、走过时吊灯摆动、无人碰时静止）；渲染回归（吊灯静止时画面不变，机关场景加入炸药拾取物）。
- 代价与风险：炸药不伤玩家、不破坏地形；冲击波推动草与藤蔓用的是三个固定方向的影响区域，而不是真正的径向力；烟雾在关闭烟雾效果（F5）时看不到。
- 重新评估条件：需要可破坏的墙或会伤人的爆炸时，在 `blast` 中加入对应的处理并为玩家伤害加开关。
