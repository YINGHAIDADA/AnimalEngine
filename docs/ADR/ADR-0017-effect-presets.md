# ADR-0017: 粒子效果预设与发射器

- 状态：Accepted
- 日期：2026-10-23
- 背景与问题：V1 的灰尘、萤火虫、火星、火花在示例游戏代码里各有一个生成函数，参数写死；房间只能用 `dust` / `fireflies` 地图属性设数量，新效果要改 C++。M3 要求“效果可在关卡数据中配置并复用”，并且有开关与性能计数。
- 决策：
  - **预设文件** `*.effect.json`（`{"format": "animal-effect", "version": 1, …}`），一个文件描述一种效果，字段全部可选：
    - 发射：`count`（保持存活数量）、`rate`（每秒）、`burst`（一次触发的数量）、`prewarm`（初始数量以随机年龄出生）、`offset` / `spreadX` / `spreadY`（点发射器的出生偏移与抖动）；
    - 运动：`velocityX/Y`、`speed` + `angle`（极坐标速度，度，0 = 右，90 = 下）、`accelerationX/Y`、`drag`、`windResponse`、`wander`、`pushResponse`、`dieOnSolid`；
    - 外观：`lifetime`（秒、范围或 `"forever"`）、`fade`、`flicker`、`startColor` / `endColor`（`"#rrggbb"` 或 `[r, g, b, a]`）、`style`（`lit`：世界 pass 中的受光像素，只在有光处可见；`glow`：光照之后的加色像素）、`halo`；
    - 光：`lightRadius`（> 0 时每个粒子带一个点光源，强度随粒子透明度变化）、`lightColor`、`lightIntensity`、`lightHeight`。
    - 范围字段写一个数或 `[min, max]`。未知字段、类型错误、格式 / 版本不符都是带文件名与字段名的错误。
  - **EffectSystem**（框架）：每个房间一个，内含 `ParticleSystem`。房间构建时登记用到的预设（同一预设对象只登记一次，最多 255 个，粒子的 `kind` 即预设编号）与发射器；`start` 生成初始数量，`step` 推进粒子、为每个发射器补足 `count`、按 `rate` 累积发射；`burst` 用于一次性事件；`draw` / `addLights` 按预设的样式绘制与加光。粒子记录来自哪个发射器（`Particle::source`），所以同一预设的多个发射器各自保持数量。随机数用每个房间的种子，`--deterministic` 下可复现。
  - **EffectLibrary**：按路径缓存解析结果（失败也缓存并记录日志），所有房间共享。
  - **Tiled**：`emitter` 对象——点对象为点发射器，矩形为区域发射器（在矩形内的非实心位置出生）；属性 `effect`（file，相对房间文件）、可选 `count`（int）与 `rate`（float）覆盖预设。蜡烛默认带 `ember` 预设、拾取宝石时触发 `spark` 预设，蜡烛可用 `effect` 属性换成别的预设。取代地图属性 `dust` / `fireflies`。
  - **开关与计数**：`EffectSystem::setEnabled`（关闭时清空粒子、不模拟不绘制不加光）；覆盖层显示每种效果的数量与上一步的 CPU 耗时，示例游戏用 F10 开关。
  - 示例：`dust`、`firefly`、`ember`、`spark` 四个预设，参数与原硬编码一致；三个房间各放一个覆盖全房间的 dust 与 firefly 区域发射器（数量与原地图属性一致，用 `count` 覆盖）。
- 主要理由：效果参数是美术数据，预设文件可复用、可在不编译的情况下调整；发射器是关卡数据，放在 Tiled 中与道具一起摆放；框架只提供通用的发射与绘制，游戏只决定“哪些道具自带哪些效果”。
- 代价与风险：仍是 CPU 粒子（GPU 粒子在 M3 后续步骤）；预设不支持继承；绘制只有 1 像素的两种样式；修改预设需重进房间才生效（没有热重载）；随机数序列与重构前不同，粒子分布与旧截图不逐像素一致（预期内）。
- 验证方式：effects 测试覆盖预设解析与各类拒绝、按发射器保持数量（含数量覆盖与寿命到期后补足）、按速率发射、爆发数量、区域出生避开实心 Tile、关闭清空与重新开启后补足、同种子结果完全相同 / 不同种子不同；示例房间中各效果与重构前观感一致；两后端截图逐像素一致，验证层零报错。
- 重新评估条件：需要预设继承、多像素 / 精灵粒子、热重载、或单房间粒子数量上万（转 GPU 粒子）时。
