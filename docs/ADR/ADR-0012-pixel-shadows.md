# ADR-0012: 硬边像素阴影

- 状态：Accepted
- 日期：2026-10-23
- 背景与问题：ADR-0007 的光照没有遮挡，光会穿过墙壁，与动物井“光从缝隙漏出、平台在背景上投下影子”的观感差距最大。M2 第一步要加阴影，且要保持像素风格（已选定硬边，不做柔和半影）、两后端逐像素一致、OpenGL 4.1 片元着色器可实现。
- 决策：
  - **遮挡图**：画布尺寸（320×180）的 R8 纹理，每个画布像素一字节，非零 = 挡光；由游戏通过 `Renderer2D::setLightOccluders` 上传（与 `setFluidObstacles` 相同的方式，画布空间，镜头移动时需重新上传）。示例游戏在进入房间时由实心 Tile 生成；角色、植被、道具不挡光。
  - **逐像素光线**：光照 pass 中，每个被光源四边形覆盖的像素从光源所在像素走到自己（整数 Bresenham），在遮挡图中查询：
    1. 光源周围的遮挡像素先跳过（光源在水晶 Tile 内部时仍能照出来）；
    2. 光线穿过一块遮挡物并再次出来 → 完全挡住（背景上的阴影边缘是硬的，任何厚度的墙都不漏光）；
    3. 目标像素自己所在的遮挡物内，光按穿入深度线性衰减，`shadowPenetration`（缺省 16 px）处为零——墙朝向光源的一面被照亮并向内变暗，再经合成的光照分级变成像素色阶。
  - **整数光线**：光源所在像素在 CPU 上算好（`floor(光源世界坐标 − 画布原点)`），以 `flat` 整数传入；路径用整数 Bresenham。最初用浮点半像素步进时，位于像素边界上的光源（Tile 中心）在两后端取整不同，出现个别像素差异；整数化后两后端逐像素一致。
  - **开关**：`LightingSettings::shadows`（F7）、`shadowPenetration`；`PointLight::castsShadows` 可按光源关闭。
- 主要理由：画布分辨率下逐像素步进很便宜（示例场景约 0.05–0.1 ms / 帧，Apple M2），不需要阴影贴图、几何体或新的 RHI 功能；“穿出即挡住 + 最后一块内衰减”同时满足背景硬阴影和墙面受光两种需求，这是只用“累计穿透深度”做不到的（深度阈值小则墙面全黑，大则薄墙漏光）。
- 代价与风险：开销与“光源覆盖面积 × 光线长度”成正比，大半径光源很多时需要在性能步骤中压测；Bresenham 会穿过两个仅以对角相接的遮挡像素之间（Tile 拼接时罕见）；遮挡图是画布空间的，滚动镜头需要每次移动后重新上传；精灵不投影。
- 验证方式：两后端在 `--demo --deterministic` 的 8 个时刻截图逐像素一致，Vulkan 验证层（含同步验证）零报错；关闭 / 打开阴影的差异图确认损失集中在平台内部深处和平台背后的背景上；水晶长廊加入一盏大半径光源，平台在其周围投下清晰的扇形阴影。
- 重新评估条件：需要精灵投影、柔和半影、滚动镜头，或光照 pass 超出帧预算时。
