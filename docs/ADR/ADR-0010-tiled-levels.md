# ADR-0010: Tiled 关卡约定与房间切换

- 状态：Accepted
- 日期：2026-10-22
- 背景与问题：PROJECT.md v1.2 选定 Tiled 作为 M4 之前的关卡编辑器。需要约定引擎读取哪些 Tiled 数据、Tile 与对象的语义如何表达，以及多个单屏房间如何拼接和切换。
- 决策：
  - **文件**：房间 = `.tmj`（JSON 地图）；Tileset = 外部 `.tsj`（也接受内嵌）；房间布局 = Tiled 世界文件 `.world`（每个房间的像素位置与尺寸）。JSON 解析使用 nlohmann/json v3.12.0。
  - **地图限制**：正交、非无限、方形 Tile（8 px）、尺寸 40×22（与世界文件中的尺寸一致）；恰好一个 Tileset；恰好一个 Tile 图层，CSV 编码（不支持 base64 / 压缩）；Tile 翻转标志被忽略并警告。违反任何一条都会给出带文件名与字段的错误。
  - **Tile 语义来自 Tileset 的自定义属性**（不在代码里写死 Tile id）：

| 属性 | 类型 | 含义 |
|---|---|---|
| `solid` | bool | 参与碰撞 |
| `grass` | bool | 露出的顶部长草 |
| `light`, `lightColor`, `lightRadius`, `lightIntensity`, `lightHeight` | bool / color / float | 该 Tile 是光源（如水晶）；其余光源属性加 `light` 前缀，见 ADR-0013 |

  - **对象**（对象图层中的点对象，`class` / 旧版 `type` 字段为类型）：

| 类型 | 位置含义 | 属性 |
|---|---|---|
| `spawn` | 角色脚底中心 | — |
| `candle` | 道具底边中心（站在表面上） | — |
| `vent` | 道具底边中心 | `rate`（烟 / 秒）、`force`（px/s²） |
| `vine` | 锚点（顶端） | `segments`（可选，缺省自动垂到下方第一个实心 Tile 上方） |
| `light` | 光源位置 | `color`、`radius`、`intensity`、`height`，以及 ADR-0013 的聚光与动画属性 |
| `lantern` | 灯具中心（链条自动挂到上方第一个实心 Tile） | 同 `light`，缺省为暖色闪烁光 |

  玩法对象 `trigger`、`gem`、`crawler` 见 ADR-0011。

  - **地图属性**：`fireflies`、`dust`（int，粒子数量）；观感（环境光、调色等）由 `look` 与 `look.*` 指定，见 ADR-0015（取代原先的 `ambient`）。
  - **起点**：世界中带 `spawn` 对象的房间。
  - **房间切换**：角色碰撞框中心离开当前房间时，按世界坐标查找包含该点的房间；找到则立即进入，角色换算到新房间坐标并保持速度与小数余量；进入房间时按其数据重建碰撞、植被、道具、光源、粒子、流体障碍，并清空烟雾。下方没有房间时，掉出 32 px 后重生（M1b 起为检查点重生，见 ADR-0011）。
- 主要理由：用现成编辑器尽早做关卡；Tile 与对象语义完全数据驱动，美术 / 关卡设计不需要改代码；世界文件直接表达单屏房间的拓扑，切换逻辑只是坐标查找。
- 代价与风险：只支持 Tiled 功能的一个子集；房间状态（如被搅动的烟、草的倾斜）在离开后不保留；目前测试世界由 `tools/scripts/make_test_world.py` 生成——在 Tiled 中编辑后应停止重新生成。
- 验证方式：level 测试覆盖内嵌 / 外部 Tileset、属性与对象解析、翻转标志、各类拒绝情况与错误信息、世界查找与重叠检测；`--demo` 从入口穿过隧道进入水晶长廊、坠入烟雾深坑，三次切换均正确；用真实房间文件做无界面模拟，确认从深坑跳回长廊可行（从坑下平台起跳并在约 0.1–0.2 s 内转向即可）。两后端截图一致，验证层零报错。
- 重新评估条件：需要多个 Tile 图层（前景 / 背景）、动画 Tile、房间内滚动镜头，或 M4 内嵌编辑器取代 Tiled 时。
