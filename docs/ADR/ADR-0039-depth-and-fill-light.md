# ADR-0039: 纵深层次与补光（后墙层、间接光、环境光遮蔽）

- 状态：Accepted
- 日期：2026-10-24
- 背景与问题：画面只有“后墙 Tile + 前景 Tile / 精灵”一个光照平面，后墙与平台受光方式完全相同，缺少纵深感；光源之外几乎全黑，整体偏暗，而增加灯光会破坏场景的明暗节奏。
- 决策：
  - **后墙层**：材质标志的 g 通道记录深度（0 = 前景，1 = 后墙）。`Renderer2D::setLayerDepth` 设置之后 lit 精灵的深度，`SpriteBatch::draw` 把它写入顶点参数；`beginWorld` 时归零。洞穴房间把不实心、无伤害的 Tile 画成后墙。合成时后墙的直接光乘 `backLight`，再向 `depthFogColor` 混合 `depthFog`（自发光不受影响）；光照 pass 中后墙法线向屏幕法线压平 `backFlatten`，砖缝的明暗变弱。
  - **间接光**：光照缓冲按 4×4 平均降采样到画布 / 4（`light_downsample.frag`，`texelFetch`），用泛光的高斯模糊（`post_blur.frag`）先宽后窄各模糊两遍，合成时按 `indirect` 加到光照里（在光照分级之前，所以仍是色阶）。放大采样在着色器里用 `texelFetch` 手动做双线性，坐标由整数像素推出：硬件过滤精度与插值 UV 在两个后端之间有细微差别。
  - **环境光遮蔽与渐变**：进入房间时（`setOccluders`）由遮挡图在 CPU 上算一张 R8 遮蔽图：每个非实心像素统计周围 13×13 内实心像素的比例（积分图），实心像素本身为 0。合成时环境光与间接光乘 `1 - ambientOcclusion × 遮蔽`，墙角、平台下方与窄缝更暗；环境光再乘自上而下的渐变 `1 + ambientGradient × (1 - 2y)`（顶部亮、底部暗）。
  - 七个新字段加入 Look（`backLight`、`backFlatten`、`depthFog`、`depthFogColor`、`indirect`、`ambientOcclusion`、`ambientGradient`），可在预设与 `look.*` 覆盖中使用，房间切换时渐变。默认值让画面与之前逐像素相同（`backLight = 1`，其余为 0）。洞穴预设：环境光 `#1a1a28`（提高），`backLight 0.8`、`backFlatten 0.3`、`depthFog 0.18`、`indirect 0.6`、`ambientOcclusion 0.7`、`ambientGradient 0.35`；水晶 / 深水 / 余烬预设各有自己色调的深度雾。
- 主要理由：三项都只改光照与合成，不新增光源、不改美术资源；全部是 Look 参数，可按房间调，默认关闭，不影响已有画面。间接光复用泛光的模糊着色器；遮蔽图只在进入房间时计算一次。
- 验证方式：默认参数下 8 个渲染回归场景与之前的基准图逐像素相同（两后端）；调好参数后更新基准图，两后端逐像素一致；单元测试检查新字段默认关闭、能解析、写入光照设置并参与渐变；洞穴三个演示场景平均亮度约提高 60%–75%。
- 代价与风险：间接光多 5 个画布 / 4 的小 pass；遮蔽只看静态 Tile（动态平台、门不产生遮蔽）；只有后墙与前景两层，没有视差。新加的项都在光照分级之前，个别像素仍可能落在舍入边界上，造成两后端最后一位不同（调参时发现过一次，换参数即消失）。
- 重新评估条件：需要视差背景层、动态物体的遮蔽或更多深度层级时，把深度扩展成多级并让相机按层偏移。
