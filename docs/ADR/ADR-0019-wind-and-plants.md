# ADR-0019: 风场与植物种类

- 状态：Accepted
- 日期：2026-10-23
- 背景与问题：V1 的风是只随 x 与时间变化的全局水平波，草只有一种且由 Tile 属性 `grass` 决定。M3 要求“植被种类与风场”，并且效果可在关卡数据中配置、复用。
- 决策：
  - **风场**（框架 `WindParams` + `windVectorAt(位置, 时间)`，单位与原来一致，1 = 微风）：
    - 基础微风：原 `windAt` 的水平波 × `strength`；
    - 阵风前锋：每 `gustInterval` 秒一道宽 `gustWidth` px 的脉冲以 `gustSpeed` px/s 横扫（符号即方向），强度 `gustStrength`（0 = 无）；
    - 局部气流 `WindSource`：从一点沿 `direction` 吹，轴两侧 `radius` px 内有效，沿 `length` 线性衰减、横向二次衰减（通风口的上升气流、隧道口吹进来的风）。
    - 草按自身中点、藤蔓按每个链节（每步采样一次）、粒子按自身位置取风的二维向量；风大于微风的部分（阵风、气流）让草叶抖动（`flutter`）。
  - **植物种类**（`PlantSpecies`，`*.plant.json`，格式 `animal-plant` v1，严格校验）：高度范围、间距、缺口比例、直立 / 下垂、弹簧刚度 / 阻尼、受风倾斜、抖动、最大弯曲、三段颜色（根 / 中 / 梢，按每根的明暗变化 ±12%），可选的花（梢上一个像素，`flowerGlow` 时不受光照、可带点光源）。
  - **`GrassField` 扩展为多种类**：每根草记录种类；`plant(地图, 区域, 种类, 种子)` 在区域内所有暴露的实心 Tile 面上生长——直立种类长在顶面，下垂种类长在底面；原来的 `generate`（Tile 属性 `grass`）保持行为，使用 0 号种类。绘制回调直接给出颜色，花另有 `forEachFlower`。`PlantLibrary` 按路径缓存（节点容器，返回的指针始终有效）。
  - **Tiled**：
    - 地图属性 `wind.strength`、`wind.gusts`、`wind.gustInterval`、`wind.gustSpeed`；
    - `wind` 点对象（`direction` 度、`strength`、`length`、`radius`）；通风口自动成为向上的气流（强度 = 推力 / 200）；
    - `plants` 矩形对象（`plant` 文件）；带 `grass` 属性的 Tile 使用 `plants/grass.plant.json`。
  - 示例：入口房间满屋垂苔、东侧隧道吹进的气流与从东向西的阵风；水晶长廊垂苔与两片发光花（各带小光源）；烟雾深坑水池岸边与水底的芦苇（梢上是棕色香蒲穗），通风口上方的气流吹动附近的草和灰尘。
- 主要理由：风场是纯函数（位置、时间），确定、可测试，所有消费者共用；植物种类与粒子、观感一样做成预设文件，关卡用矩形对象摆放，不需要新的 Tile 或美术。
- 代价与风险：气流不读取 GPU 流体速度场（通风口的气流是独立的近似）；植物不与 Tile 以外的东西（水面、平台边缘的半格）对齐；每根草每步计算一次风（725 根时 CPU 开销可忽略）；草的像素逐个以四边形绘制（入口房间精灵数约 3.6k → 5.5k）。
- 验证方式：wind 测试覆盖阵风方向、窄脉冲与传播速度、气流沿轴衰减与边界、粒子在上升气流中上升、植物预设解析与拒绝、按区域在顶面 / 底面生长与下垂绘制、强气流中持续抖动与无风时回正；原有草 / 藤蔓测试全部通过；三个房间截图检查；两后端截图逐像素一致，验证层零报错；入口房间帧时间在测量噪声内无变化。
- 重新评估条件：需要风与流体耦合、植物精灵（非像素线）、或草的数量上万时。
