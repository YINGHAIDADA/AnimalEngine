# ADR-0029: 内嵌关卡编辑器：直接编辑 Tiled 文档

- 状态：Accepted
- 日期：2026-10-23
- 背景与问题：M4 验收要求“不修改引擎代码即可摆放实体、光源、触发器并快速测试”。关卡此前只能在 Tiled 中编辑或由脚本生成，改完要重新构建、重启才能看到。需要决定编辑器保存什么格式，以及它和 Tiled 的关系。
- 决策：
  - **数据**：编辑器直接编辑房间的 `.tmj` JSON 文档（`devtools::TiledMap`，保持成员顺序），不另设格式：Tiled 与内嵌编辑器编辑同一份文件，引擎不认识的字段和 Tiled 自己的记录都原样保留。写出格式与 Tiled / 生成脚本一致（一格缩进、ASCII），未修改的房间往返后逐字节相同。新对象的 id 取 `nextobjectid` 与现有最大 id 之后的值，**从不复用**（宝石的存档键依赖它）。
  - **实时生效**：每次编辑后把文档序列化，用游戏加载关卡的同一个 `parseRoom` 解析，成功则替换房间数据并重建当前房间（玩家位置不变）；解析失败（或地图尺寸与世界文件不符）时不应用，并在编辑器中显示原因。
  - **操作**（Tab 进入 / 退出，进入时自动显示工具界面）：选择 / 移动 / 拖动右下角改矩形大小（吸附 1 / 2 / 4 / 8 px）；放置任意对象类型（列表或 1–9 / 0、`[` `]`，带默认属性）；Tile 画笔与矩形填充（右键擦除，Alt 取色）；检查器编辑类型、名称、位置、尺寸与带类型的自定义属性（文件属性给出预设文件列表，颜色用拾色器，“Add property”列出该类型认识的属性）；房间属性（`look`、`look.*`、`wind.*`）；撤销 / 重做（整份文档快照，200 步）；Ctrl+S 保存到源文件与部署副本；每个房间单独记录未保存状态，可“Save all”；右键菜单“把玩家移到这里”。叠加层（网格、对象轮廓 / 标记 / 标签、选中与笔刷预览）用 ImGui 背景绘制列表画在窗口分辨率上。
  - **试玩**：编辑时玩家冻结、房间里的植物 / 粒子 / 甲虫照常运动；再按 Tab 立即从当前状态继续游戏，不需要保存或重启。
  - **对象模板**属于游戏（`level_editor.cpp` 中的列表：类型、点 / 矩形、默认尺寸、初始属性、可添加属性），引擎与 `TiledMap` 不知道任何对象语义。
  - **自动化**：引擎新增 `--input-script=path`，在指定帧注入按键 / 鼠标（画布像素坐标）/ 文本事件（与真实输入合并），用来测试编辑器与做验收演示。
  - `make_test_world.py` 从此不再覆盖已存在的房间（需要 `--force`），避免抹掉编辑结果。
  - **世界布局**（补充）：`devtools::TiledWorld` 同样直接编辑 `.world` 文档。World 窗口按比例显示所有房间：拖动房间（按整房间或 8 px 吸附，重叠时标红并拒绝）、双击传送、右键从世界中移除房间（当前 / 起点 / 检查点房间除外，文件保留在磁盘上）、撤销布局修改。“New room”在当前房间旁的空位创建房间：空房间（按 Tileset 属性选背景、带草地面与墙的地板，沿用观感与风）或当前房间的副本（房间名不同，所以宝石存档键不同），写入后立即传送过去。每次布局修改先由游戏的世界解析器检查（重叠、尺寸），再写入源文件与部署副本并重新加载世界；游戏拒绝时恢复原文件。房间名只允许 a-z、0-9、_（它是存档键）。
  - CMake 改为按目录收集 `assets/source/world` 与 `textures` 下的文件（`CONFIGURE_DEPENDS`），编辑器新建的房间会进入之后的构建。
- 主要理由：继续使用 Tiled 格式意味着零迁移成本，复杂的批量编辑仍可在 Tiled 中完成，内嵌编辑器负责“边玩边改”；用游戏自己的解析器应用编辑，保证编辑器看到的就是游戏加载到的。
- 代价与风险：只支持未压缩的 Tile 数据（Tiled 的 CSV / JSON 数组，项目当前格式）；房间尺寸固定为当前房间的尺寸，不支持改名和删除房间文件（在文件系统中处理）；撤销快照是整份文档，房间很大时内存会增加（当前每份约几十 KB）。
- 验证方式：单元测试（三个房间与世界文件往返逐字节相同；Tile、对象、属性、世界布局操作；id 不复用）；输入脚本测试世界窗口：新建房间（地板 Tile 正确、自动传送）、拖到重叠位置被拒绝、拖到空位被保存、撤销后恢复；输入脚本测试：放置灯 / 触发器 / 甲虫并拖动后保存，diff 只包含新增对象与 `nextobjectid`；放置后撤销不留痕迹；画笔与右键矩形擦除只改动对应 Tile；放置后按 Tab 试玩，走进新触发器显示提示。
- 重新评估条件：需要多图层 Tile、旋转 / 翻转、新建房间或世界布局编辑时扩展；编辑器复杂到影响游戏迭代时考虑独立程序。
