# ADR-0014: 像素边缘光

- 状态：Accepted
- 日期：2026-10-23
- 背景与问题：角色和敌人的像素画外圈是近黑色描边。在暗处，Lambert 光照乘到描边上几乎看不见，角色轮廓读不出来；动物井的角色在背光或侧光时会有一像素宽的亮边。M2 要加边缘光，并保持硬像素风格、两后端逐像素一致。
- 决策：
  - **哪些像素接收边缘光**：由精灵决定。`SpriteMaterial::rim`（0–1）经精灵顶点的一个 UNorm8 参数传给材质 pass；材质 pass 新增第四个颜色附件“材质标志”（RGBA8，r = 边缘光强度 × 覆盖率，a = 覆盖率，预乘混合），所以前面的精灵会正确地遮住后面精灵的标志。最初尝试把强度放进自发光的 alpha，但那个 alpha 同时是自发光颜色的混合因子，不接收边缘光的精灵会因此不再遮住下面的自发光，于是改成独立附件。
  - **受光边缘光**（光照 pass，每个光源）：若像素的边缘光强度 > 0，而它朝向光源的相邻像素（8 邻域，用整数比较选择：偏离坐标轴约 27° 以内取轴向，否则取对角）强度为 0，则它是朝向该光源的轮廓像素，向第二个加色目标（RGBA16F）写入 `光色 × 衰减 × 聚光因子 × 阴影可见度 × 强度 × rimIntensity`。不乘法线 Lambert，也不乘 albedo。
  - **环境边缘光**（合成）：边缘光强度 > 0、且上 / 左 / 右任一邻居为 0 的像素，加上 `rimAmbient × 强度`（不含底边，因为角色通常站在地面上）。暗处的角色也有一圈淡轮廓。
  - **合成**：`albedo × 光照（分级）+ 自发光 + 环境边缘光 + 受光边缘光`。边缘光在光照分级之后相加，不参与色阶量化（它本来就是一像素宽的线）；关闭光照（F3）时也关闭边缘光。
  - **参数**：`LightingSettings::rimIntensity`（缺省 1）、`rimAmbient`（缺省 (0.10, 0.10, 0.14)）。示例游戏中角色与甲虫的材质 `rim = 1`。
- 主要理由：在像素尺度上，“朝向光源的邻居是空的”就是轮廓朝向光源的精确定义，比用法线贴图边缘的倾斜更干净，也不会让砖块等 Tile 的内部纹理出现亮边；加色、不乘 albedo，所以深色描边正好成为亮边；整数选邻居保证两后端访问完全相同的像素。
- 代价与风险：多一个 RGBA8 与一个 RGBA16F 画布尺寸目标（共约 0.7 MB）；轮廓只看边缘光精灵之间的覆盖，边缘光精灵站在不接收边缘光的精灵（如草）后面时，被遮住的边不会亮；光源正好位于轮廓像素上时该光源不产生边缘光；Tile 没有边缘光（可将来按 Tile 属性扩展）。
- 验证方式：放大截图确认角色朝向左侧水晶的一侧出现蓝色轮廓、底边被下方烛光照成暖色，暗处甲虫顶部有淡轮廓；两后端在 `--demo --deterministic` 三个时刻截图逐像素一致，Vulkan 验证层零报错；Release 帧时间无可测变化。
- 重新评估条件：需要 Tile 边缘光、边缘光宽度大于 1 像素，或按房间调整边缘光参数时（后者计划在 M2 的房间光照配置中做）。
